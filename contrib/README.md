# contrib

Packaging and integration files, added in the distribution phase:

- `npm/`: npm wrapper package that downloads the platform binary so `npx furcule mcp` works in MCP configs.
- `aur/PKGBUILD`: Arch Linux package.
- `homebrew/furcule.rb`: formula for the `y0sif/homebrew-tap` tap.
- `systemd/furcule.service`: user unit for `furcule serve`.
