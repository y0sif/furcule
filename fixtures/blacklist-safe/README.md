# Fixture: The safe (The Blacklist)

The scene that started the project. Facts: the recordings are gone; only two people could open the safe; one is dead; the other did not open it. Assumption: the only way to the recordings is to open the safe. Negating it opens the branch: the whole safe was replaced with an empty replica.

Files, added in the testing phase:
- `input.md`: the source text the extractor runs on.
- `expected.json`: the assumption and inference nodes a correct extraction must contain, and the conclusions that must fall when the key assumption is negated.
